Ask the Memory

The canonical world: 90 dated notes about a small company. Pick a question to see what each of the 11 systems answered in round 1 — or ask your own question live to the cheap-write systems on the same model.

Break the Memory

Write a fact, then an update that supersedes it, then (optionally) an unverified note that contradicts both. Ask a question. See which systems answer with the current value, the stale one, or the poison — and which notes each one actually retrieved. 15 unrelated notes are mixed in so retrieval has to work.

Generator: one model for every system (see /health) · embedder bge-small-en-v1.5 · judge strict-v3 · live requests are capped per visitor and by a hard daily budget; the ledger above is live. Source: github.com/B-cmd-alt/memory-evaluator.
